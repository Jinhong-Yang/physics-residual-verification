# v0.4 follow-up replay

From the extracted Overleaf directory run `python tools/run_followup_study.py` using Python 3.11, NumPy, SciPy and PyTorch (the same dependencies as the extended study). It runs Laplace, VLM-free MAP, development-selected 87-dimensional representation comparisons, real-unit correction scoring, calibration scoring and the pooled action-statistic audit. Reference arrays in evidence/followup/reference_results are compared at absolute tolerance 1e-12. Outputs are written to replayed/followup.

The original 129 evidence hashes and frozen numeric/full predictions are checked. No evaluation outcomes select hyperparameters. Original geometry confirmation is an old, inspected cohort for the new analyses, not a new confirmatory trial. Separate fresh-family prediction and target-access receipts document calibration ordering. The local plan is not a public preregistration.

This replay uses cached feature arrays. Raw RGB companion archives, source closure, indexes and hashes support inspection and re-extraction in the stated Windows/WSL research environment; GPU model weights and real videos are external dependencies. The new RGB archive has no clean-environment installation claim. OpenCV is needed for raw Lucas-Kanade and real tracking extraction. See its README_FOLLOWUP_RGB.md.

Laplace is the local Gaussian/Gauss-Newton marginal at the joint MAP, not full non-Gaussian integration. Point means are therefore identical to that joint fit. The public radius is empirical; new synthetic conformal scaling fails the requested episode coverage band. Family-maximum and episode-marginal coverage are different events. Reported component extraction timing is not a matched end-to-end latency benchmark.
